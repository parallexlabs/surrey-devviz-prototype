# GitHub Pages

The static demo is built into this `docs/` folder with base path `/surrey-devviz-prototype/`.

When GitHub Pages is enabled for this repository (source: branch `main` or `showcase-visual-1`, folder `/docs`), the public URL will be:

https://parallexlabs.github.io/surrey-devviz-prototype/

The full demo recording (`media/demo.mp4`) is kept under `showcase-media/demo.mp4` locally until release assets or Pages deployment include files over 2 MB. After Pages is on, copy or attach that file so the README link to `https://parallexlabs.github.io/surrey-devviz-prototype/media/demo.mp4` works.

The primary live demo remains https://parallexlabs.ca/demos/surrey/
